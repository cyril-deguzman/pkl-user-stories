User Stories

PKL Boost is a verified-creator add-on inside PKLPlace that lets influencers, court owners, and tournament organizers promote their videos into the PKLLife reels feed. This document captures the user stories grouped by epic, following the classic "As a… I want… so that…" format with acceptance criteria.

PERSONAS

Who we are designing for

🏆
Tournament Organizer
Verified Partner
Runs leagues and tournaments. Wants more registrations and visibility for upcoming events.
Goals Drive event signups · Reach players in target cities · Show ROI on ad spend
🏟️
Court Owner
Verified Partner
Operates one or more pickleball courts. Wants to fill bookings and grow recurring players.
Goals Increase court bookings · Promote clinics · Target by location & skill
⭐
Influencer / Pro Shop
Verified Partner
Sells gear, coaching, or content. Wants reach into the most engaged pickleball audience.
Goals Sell products · Build a following · Boost specific videos
EPIC 1

Partner Dashboard & Overview

— a single landing surface for active campaigns, key metrics, and wallet status.
EP-01 Dashboard & Overview
5 stories
US-001
As a verified partner, I want to see my key performance metrics (spend, views, CTR, active campaigns) at a glance when I open the Boost page, so that I can quickly assess whether my campaigns are healthy without digging into reports.
Must3 pts
Acceptance Criteria
✓
Dashboard shows 4 KPI cards: Total Spend, Active Campaigns, Total Views, Average CTR.
✓
Each card shows the current month's value and a delta vs the previous month.
✓
Metrics refresh on page load and within 5 seconds of any campaign data change.
✓
Empty state shown if the partner has no campaigns yet, with a CTA to create one.
US-002
As a partner, I want a recent-campaigns table on the dashboard with status, budget, spend, views, clicks, and CTR, so that I can spot which campaigns are performing best without leaving the page.
Must3 pts
Acceptance Criteria
✓
Table shows up to 5 most recent campaigns ordered by createdAt desc.
✓
Status pill renders Active / Paused / Ended with a colored dot.
✓
Clicking a row opens the campaign detail page.
✓
"View All" button navigates to the full Campaigns list.
US-003
As a partner, I want a wallet widget on the dashboard showing my balance and a quick top-up shortcut, so that I never accidentally let my campaigns run out of funds.
Must2 pts
Acceptance Criteria
✓
Widget displays current balance in PHP, last updated timestamp.
✓
Shows a "runway" estimate (e.g. "Sufficient for ~1.6 days").
✓
Quick Top-Up button opens the top-up modal pre-focused.
✓
If balance < 24h runway, widget shows a low-balance warning state.
US-004
As a partner, I want in-app notifications for campaign events (low balance, campaign ended, milestones reached), so that I can react before issues affect my reach.
Should5 pts
Acceptance Criteria
✓
Bell icon shows unread count.
✓
Tapping opens a panel with notifications grouped by date.
✓
Notifications include campaign name and link to detail page.
✓
Read state persists across sessions.
US-005
As a partner, I want to access the Boost dashboard only if I am a verified PKLPlace user, so that the system enforces our partner eligibility rules.
Must3 pts
Acceptance Criteria
✓
Unverified users see an explainer screen with steps to apply for verification.
✓
Verification status is read from the PKLPlace user record (no duplicate flow).
✓
Once verified, dashboard loads automatically without a re-login.
EPIC 2

Boost a Video (Campaign Creation)

— the core flow: pick a video, choose audience, set budget, review, launch.
EP-02 Boost a Video
6 stories
US-006
As a partner, I want to select an existing PKLLife video from my library to boost, so that I can promote content I have already published.
Must5 pts
Acceptance Criteria
✓
Video grid shows all videos uploaded by the partner with thumbnail, title, duration.
✓
Only one video may be selected per campaign.
✓
Videos that violate community guidelines are filtered out and shown in a separate "ineligible" group.
US-007
As a partner, I want to upload a new video directly during campaign creation, so that I don't have to switch contexts to publish first.
Should8 pts
Acceptance Criteria
✓
Supports MP4 / MOV up to 100MB and 60 seconds.
✓
Upload progress is shown; failures show an actionable error.
✓
Newly uploaded videos enter PKLLife moderation queue automatically.
✓
Campaign cannot launch until video is approved.
US-008
As a partner, I want to target my campaign by location, age, gender, DUPR skill bracket, and home court, so that my video reaches the right audience and I don't waste budget.
Must8 pts
Acceptance Criteria
✓
Location supports city/region from a dropdown of valid PH cities (multi-select v2).
✓
Age range is two numeric inputs (min 13, max 99); validated min ≤ max.
✓
Gender: All / Male / Female single-select.
✓
Skill levels are multi-select DUPR brackets (Beginner / Intermediate / Advanced).
✓
Home Court is single-select from active courts in PKLPlace, plus "Any Court".
✓
Estimated reach updates within 1s of any criteria change.
US-009
As a partner, I want to set a total budget and duration with live cost summary, so that I always know exactly what I'll spend before launching.
Must5 pts
Acceptance Criteria
✓
Minimum budget is ₱100; max is ₱100,000 per campaign.
✓
Duration presets: 3, 5, 7, 14 days; custom range optional.
✓
Live summary shows daily budget, total cost, estimated reach, balance after launch.
✓
Warning if total cost > wallet balance, with a Top-Up CTA inline.
US-010
As a partner, I want a live phone-mockup preview of how my ad will appear in the PKLLife feed, so that I can validate placement and copy before paying.
Should3 pts
Acceptance Criteria
✓
Mockup updates as the partner picks a video and edits CTA.
✓
Mockup includes "Sponsored" label matching production styling.
US-011
As a partner, I want to review every setting on a single confirmation step before paying, so that I can catch mistakes before money is taken from my wallet.
Must2 pts
Acceptance Criteria
✓
Review step lists video, audience, budget, and duration grouped by section.
✓
Each section has an "Edit" link that returns to that step.
✓
Launch button is disabled if any required field is missing.
✓
On launch, wallet is debited atomically and the campaign is queued for delivery within 30 minutes.
EPIC 3

Campaign Management

— managing existing campaigns: viewing details, pausing, editing, ending.
EP-03 Campaign Management
5 stories
US-012
As a partner, I want a Campaigns page that lists every campaign with filters by status, so that I can find and audit a specific campaign quickly.
Must3 pts
Acceptance Criteria
✓
Filters: All, Active, Paused, Ended with counts.
✓
Pagination at 25 rows per page.
✓
Searchable by campaign name (case-insensitive).
US-013
As a partner, I want a campaign detail page with views, clicks, CTR, spend curve, and demographic breakdowns, so that I can understand who is engaging with my content.
Must8 pts
Acceptance Criteria
✓
KPIs: Views, Clicks, CTR, Spend, Cost per View.
✓
Daily spend & performance line chart for campaign duration.
✓
Breakdown chips for age bracket, gender, court, and city.
✓
Data is shown with at most 30 minutes of delay.
US-014
As a partner, I want to pause and resume an active campaign, so that I can stop spend immediately if something goes wrong.
Must3 pts
Acceptance Criteria
✓
Pause stops delivery within 5 minutes; resume starts again within 30 minutes.
✓
Status updates visible across dashboard, campaigns list, and detail.
✓
Spend stops while paused; remaining budget is preserved.
US-015
As a partner, I want to edit a running campaign's audience or top up its budget mid-flight, so that I can react to performance without starting over.
Should5 pts
Acceptance Criteria
✓
Editable: audience filters, daily budget cap, end date.
✓
Not editable: video selection (must end & recreate).
✓
Edits create an audit log entry visible to admins.
US-016
As a partner, I want to end a campaign early and have unused budget returned to my wallet, so that I'm not penalized for stopping.
Must3 pts
Acceptance Criteria
✓
"End Campaign" requires a confirm dialog showing refund amount.
✓
Refund posts to wallet within 5 minutes as a "Refund" transaction.
✓
Status changes to Ended; cannot be reactivated.
EPIC 4

Wallet, Top-Up & Billing

— prepaid wallet, payment methods, and the transaction ledger.
EP-04 Wallet & Billing
5 stories
US-017
As a partner, I want to top up my wallet via GCash or credit card, so that I can fund campaigns using payment methods I already use.
Must8 pts
Acceptance Criteria
✓
Quick-amount buttons (₱500, ₱1,000, ₱2,500, ₱5,000) plus custom amount input.
✓
Successful payment credits wallet within 60s and creates a Top-Up transaction.
✓
Failed payments do not credit wallet and surface the gateway error message.
✓
Receipt is emailed to the partner.
US-018
As a partner, I want to save and manage my payment methods, so that I don't have to re-enter card details every time.
Should5 pts
Acceptance Criteria
✓
Add / remove methods; mark one as default.
✓
Card numbers are tokenized via the gateway; only last-4 stored.
US-019
As a partner, I want to enable auto top-up when my balance falls below a threshold, so that my campaigns never stop unexpectedly.
Could5 pts
Acceptance Criteria
✓
User sets threshold and top-up amount.
✓
Auto top-up uses the default payment method.
✓
Notification fires on every auto top-up event.
US-020
As a partner, I want a transaction history with filters and export, so that I can reconcile my spending for accounting.
Must3 pts
Acceptance Criteria
✓
Filters: type (Top-Up, Spend, Refund), date range.
✓
Each row shows date, description, amount, running balance.
✓
CSV export of currently filtered rows.
US-021
As a partner, I want to download a tax-ready receipt for any top-up, so that I can claim it as a business expense.
Should3 pts
Acceptance Criteria
✓
PDF receipt includes business info, transaction id, VAT line.
✓
Generated on demand from transaction record.

EPIC 6

Ad Delivery into PKLLife

— how a boosted video actually shows up in the PKLLife reels feed.
EP-06 Ad Delivery
3 stories
US-025
As a PKLLife viewer, I want sponsored videos to be clearly labeled and feel native to the feed, so that the experience stays trustworthy.
Must5 pts
Acceptance Criteria
✓
"Sponsored" label is visible on every boosted video.
✓
Sponsored videos respect the same playback & like/comment UX as organic.
✓
Frequency cap: same partner ad shown ≤ 3× per user per day.
US-026
As the Ad Delivery service, I want to match active campaigns to viewing users based on targeting filters and budget remaining, so that we deliver impressions efficiently.
Must13 pts
Acceptance Criteria
✓
For each feed request, return at most 1 ad per N organic videos (configurable).
✓
Eligibility considers: status=Active, daily budget remaining, audience match.
✓
Selection ranks by pacing target so spend is roughly even across the day.
US-027
As the Metrics pipeline, I want to record impression, view, and click events from PKLLife and roll them up into per-campaign aggregates, so that partners see accurate numbers.
Must8 pts
Acceptance Criteria
✓
Events are deduplicated by (userId, campaignId, eventType, minute).
✓
Aggregates are written to a campaign metrics collection at most every 5 minutes.
✓
Spend is debited from wallet based on a transparent CPM/CPV table.
